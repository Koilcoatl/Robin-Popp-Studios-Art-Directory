The Robin Popp Studios Art Directory (Beta Version 0.9.0) is my second entry into my professional coding portfolio.

There are many quirks with this version, but as it is it is completed.

Keep in mind, the shapes of boxes may change as you add more photos.  If you add a lot, it may start to populate below the box, and that is because I havent added in a scrollbar yet.  If you run into any errors, please contact Micah Popp at micahispopp@gmail.com

Some other known issues:
- If you add too many images to an art piece, they may stretch the edit frame too wide.
- If you add a very wide image, it will also stretch out the edit frame very wide.
- Adding images to an existing piece of art that says "no images" will not delete the "no images" picture, this will have to be deleted by hand.
- The Red X that appears when you delete an image is ugly and needs tweaking.

HOW TO:

To add a new piece of art, simply click the Art Entry button from the top menu.  This will prompt you to enter information.

To view added images, simply click the Art Directory button from the top menu, and then click the picture of the art you want to view/edit

The sort button on the directory will organize the art by certain listed criteria
